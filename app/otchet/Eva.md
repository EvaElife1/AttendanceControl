## 2. Реализованный функционал

- MainActivity: заголовок приложения и три кнопки: «Студенты», «Отметить посещаемость», «Статистика».
- StudentsActivity: экран-заготовка списка студентов.
- AttendanceActivity: экран-заготовка отметки посещаемости.
- StatisticsActivity: экран-заготовка статистики.
- Навигация: реализованы переходы между экранами через Intent.

## 4. Технические решения

- Язык разработки: Kotlin.
- Интерфейс: XML + Activity (View-based).
- Навигация: явные Intent между Activity.
- Для UI-тестов QA добавлены android:id к корневым элементам экранов (studentsRoot, attendanceRoot, statisticsRoot).
