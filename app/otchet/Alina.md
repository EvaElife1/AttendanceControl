## 2. Реализованный функционал

- Модель `Student`: поля id, firstName, lastName, groupName.
- Экран «Студенты»: поля ввода «Фамилия», «Имя», «Группа», кнопка «Добавить» и список студентов.
- Проверка ввода: пустые поля и поля из одних пробелов отклоняются, у поля показывается сообщение об ошибке.
- Добавление: корректная запись появляется в списке, поля очищаются, показывается сообщение «Студент добавлен».
- Удаление: кнопка «Удалить» в строке списка открывает диалог подтверждения; после подтверждения студент исчезает из списка, при отмене остаётся.
- Список обновляется после добавления и удаления.

## 4. Технические решения

- Язык: Kotlin, интерфейс: XML + Activity (View-based).
- Список выводится через `RecyclerView` с отдельным адаптером `StudentAdapter`.
- Данные пока хранятся во временной коллекции в памяти (`MutableList<Student>`); постоянное хранение через Room планируется в спринте 4.
- Идентификатор студента формируется счётчиком `nextId`.
- Ошибки ввода показываются через `setError` у полей, подтверждение удаления через `AlertDialog`.
- Корневому элементу экрана сохранён `android:id="@+id/studentsRoot"`, на него опираются UI-тесты QA.
- Изменения выполнены в отдельной ветке `feature/add-student`, оформлен Pull Request в `master`.
