---

## 2. Что было сделано

### 2.1. Модель данных Attendance

Создана модель для хранения отметки посещаемости:

```kotlin
data class Attendance(
    val studentId: Int,
    val lessonDate: String,
    val subject: String,
    val status: String
)
```

Поля:
- `studentId` — идентификатор студента
- `lessonDate` — дата занятия
- `subject` — дисциплина / тема
- `status` — статус (Присутствовал / Отсутствовал / Опоздал)

### 2.2. Экран создания занятия

Реализован экран, на котором преподаватель может:
- Выбрать учебную группу
- Выбрать дату занятия
- Указать дисциплину / тему (необязательно)
- Перейти к списку студентов для отметки

### 2.3. Экран отметки посещаемости

Реализован основной экран спринта:
- Отображается список студентов выбранной группы
- Для каждого студента предусмотрен выбор статуса через **RadioGroup** (или Spinner)
- Доступны три статуса:
    - Присутствовал
    - Отсутствовал
    - Опоздал
- Статус можно изменить до окончательного сохранения
- После сохранения отметки фиксируются

### 2.4. Логика одной отметки

Реализовано правило:
> На одного студента и одно занятие может быть только одна итоговая отметка.

При повторном выборе статуса старое значение заменяется новым.

### 2.5. Обработка пустого списка

Если в выбранной группе нет студентов, отображается понятное сообщение вместо пустого экрана.
