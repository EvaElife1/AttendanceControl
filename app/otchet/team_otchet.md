**Цель спринта:** добавить просмотр истории и подсчёт пропусков, улучшить интерфейс и выполнить комплексную проверку.

**Результат спринта:** реализован экран статистики с фильтрацией по студенту, группе и дате; подсчёт статусов (присутствовал, отсутствовал, опоздал); обработка пустого результата; расширен набор тест-кейсов (не менее 10); подготовлена инструкция пользователя и отчёт о дефектах.

**Критерии готовности (выполнены):**
- статистика совпадает с тестовыми данными;
- фильтры работают;
- пустые данные обрабатываются;
- основные функции проходят регрессионную проверку.

**Проблемы и решения:**
- *Проблема:* при первом запуске экрана статистики счётчики показывали некорректные значения из-за отсутствия фильтрации по умолчанию.  
  *Решение:* добавлена обработка `null`-фильтров в DAO-запросах (условия `:param IS NULL OR field = :param`).
- *Проблема:* при пустой базе экран статистики «падал» с `NullPointerException`.  
  *Решение:* добавлена проверка на пустой список и вывод сообщения «Нет данных для отображения».

**Передача ролей:** в конце дня ответственный зафиксировал выполненное, незавершённые задачи (улучшение сообщений об ошибках), ошибки и дальнейшие действия. Роли переданы по таблице ротации.
