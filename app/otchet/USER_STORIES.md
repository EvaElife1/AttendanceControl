# USER STORIES  
**Проект:** Система контроля посещаемости студентов  
**Спринт 1** | Роль: Product Owner

---

## 1. Описание проблемы

В колледже учёт посещаемости студентов обычно ведётся вручную (в журнале или Excel). Это приводит к следующим проблемам:

- Преподаватель тратит много времени на заполнение журнала.
- Легко допустить ошибку при подсчёте пропусков.
- Сложно быстро посмотреть статистику по конкретному студенту или группе.
- Нет удобного способа отметить опоздание.
- Данные хранятся только на бумаге или в разных файлах и могут потеряться.

**Решение:** создать простое мобильное Android-приложение, которое позволит преподавателю быстро отмечать посещаемость, хранить данные на устройстве и сразу видеть статистику.

## 2. User Stories

### US-01. Главный экран
**Как** преподаватель,  
**я хочу** видеть главное меню с понятными кнопками,  
**чтобы** быстро перейти к нужному разделу приложения.

**Критерии приёмки:**
- [ ] На экране отображается название приложения
- [ ] Есть три кнопки: «Студенты», «Отметить посещаемость», «Статистика»
- [ ] При нажатии на кнопку открывается соответствующий экран

---

### US-02. Просмотр списка студентов
**Как** преподаватель,  
**я хочу** видеть список всех студентов,  
**чтобы** понимать, кого я отмечаю.

**Критерии приёмки:**
- [ ] Открывается экран со списком студентов
- [ ] Для каждого студента видны фамилия, имя и группа
- [ ] Список можно прокручивать, если студентов много

---

### US-03. Добавление студента
**Как** преподаватель,  
**я хочу** добавлять нового студента,  
**чтобы** вести актуальный список группы.

**Критерии приёмки:**
- [ ] Есть возможность ввести фамилию, имя и группу
- [ ] Нельзя сохранить студента с пустыми обязательными полями
- [ ] После сохранения студент появляется в списке

---

### US-04. Удаление студента
**Как** преподаватель,  
**я хочу** удалять студента из списка,  
**чтобы** убирать тех, кто больше не учится в группе.

**Критерии приёмки:**
- [ ] Можно удалить студента
- [ ] Перед удалением появляется подтверждение
- [ ] После удаления студент исчезает из списка

---

### US-05. Отметка посещаемости
**Как** преподаватель,  
**я хочу** отметить статус каждого студента на занятии (присутствовал / отсутствовал / опоздал),  
**чтобы** фиксировать посещаемость.

**Критерии приёмки:**
- [ ] Можно выбрать дату и дисциплину/тему занятия
- [ ] Для каждого студента можно выбрать один из трёх статусов
- [ ] Статус сохраняется
- [ ] Можно изменить статус до окончательного сохранения

---

### US-06. Просмотр статистики
**Как** преподаватель,  
**я хочу** видеть статистику посещаемости (количество присутствий, пропусков и опозданий),  
**чтобы** понимать, кто часто отсутствует.

**Критерии приёмки:**
- [ ] Отображается количество занятий, присутствий, пропусков и опозданий
- [ ] Можно посмотреть статистику по студенту или группе
- [ ] Если данных ещё нет — показывается понятное сообщение

---

### US-07. Сохранение данных
**Как** преподаватель,  
**я хочу**, чтобы все данные сохранялись после закрытия приложения,  
**чтобы** не вводить информацию заново.

**Критерии приёмки:**
- [ ] После перезапуска приложения студенты и отметки остаются
- [ ] Данные не теряются при выключении устройства

| №  | Название экрана              | Назначение                                      | Статус      |

| 2  | **Студенты**                 | Просмотр, добавление и удаление студентов      | Планируется |
| 3  | **Отметка посещаемости**     | Создание занятия и отметка статусов студентов  | Планируется |
| 4  | **Статистика**               | Просмотр истории и подсчёт пропусков/опозданий | Планируется |
