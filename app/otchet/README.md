# AttendanceControl

**Проект:** «Система контроля посещаемости студентов»  
**Роль:** Product Owner (PO)  
**Исполнитель:** Алина  
**Текущий спринт:** 2

---

## 1. Назначение

Android-приложение для учёта посещаемости студентов колледжа.  
Основной пользователь — преподаватель или куратор учебной группы.  
Приложение предназначено для локального использования на одном Android-устройстве.

---

## 2. Требования

- Android Studio
- Kotlin
- Android SDK
- Git (для контроля версий)

---

## 3. Запуск проекта

1. Открыть проект в Android Studio.
2. Выполнить синхронизацию Gradle.
3. Собрать проект (`Build → Make Project`).
4. Запустить на эмуляторе или физическом устройстве.

---

## 4. Текущие возможности

### Спринт 1
- Главный экран с названием приложения.
- Кнопки: «Студенты», «Отметить посещаемость», «Статистика».
- Навигация между экранами через `Intent`.
- Экраны-заготовки: `StudentsActivity`, `AttendanceActivity`, `StatisticsActivity`.

### Спринт 2
- Экран списка студентов.
- Форма добавления студента: фамилия, имя, учебная группа.
- Валидация обязательных полей (пустые поля и пробелы отклоняются).
- Удаление студента с подтверждением.
- Сообщения: «Студент добавлен», «Заполните все обязательные поля».

---

## 5. Ограничения

- Данные хранятся в памяти в рамках сеанса.
- Постоянное хранение (Room) будет подключено в Спринте 4.
